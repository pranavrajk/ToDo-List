# 📝 To-Do List (Python CLI)
A simple command-line To-Do List application built with Python. This app allows you to:

Add tasks

Delete tasks

View tasks by day

Store tasks persistently using a JSON file

## 📦 Features
✅ Add tasks by day (e.g., Monday, Tuesday)

🗑️ Delete tasks by their number

📅 View tasks for a specific day or all days

💾 Tasks are saved between sessions using tasks.json
